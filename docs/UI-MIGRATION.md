解密导出复用 GameFileDumper，文件名和玩家目录保持原格式，不输出加密 Header。文件夹导出在所选目录内新建带时间与唯一后缀的 NHSE 子目录，避免覆盖已有存档文件。解密导入要求选择同版本导出的 main.dat，拒绝含 mainHeader.dat 的加密目录；在读入前检查当前已加载文件的长度，再列出实际将替换的文件供最终确认。仅导入存在且匹配当前存档的文件，缺失文件保持原样；长度不匹配、缺少 main.dat 或未知路径在写入前整批拒绝。不推断同尺寸解密文件的实际游戏版本，也不增加跨版本转换。整次跨文件导入作为一步撤销，未改变的文件不增加历史，取消或错误不修改存档。

## 主画布连续拖动与图片库助手

主地图画布在适应窗口的 100% 比例下也可直接平移视野并跨分区，不再仅依赖略缩图。点击“拖动画布”或按 H 后用左键拖动；空格+左键及鼠标中键提供临时平移，V 返回选择，B 开启地形笔刷。普通左键仍用于点击与矩形框选。放大后的滚动区域先正常平移，到达边缘后继续跨分区；拖动期间以全岛地形预览补齐相邻区域，松开后载入目标分区的详细图像与可编辑格子。平移位置连续保留，略缩图同步显示视野。新露出的相邻分区也可点击定位，按实际内容区域而非边框计算格子坐标。

没有编辑草稿时，平移只发送读导航请求，不写地形、物品或建筑；已有有效草稿沿用导航前应用规则。Esc、指针取消、窗口失焦或被无效草稿阻止的导航会恢复拖动前视野；切换缩放会取消当前拖动，适应窗口会重新居中当前分区。保留原有多选、剪贴板与整笔刷写入行为。地图属性区明确区分未应用草稿、已应用但未保存及已保存状态。

图片库助手位于“应用设置”和“岛屿工具”，支持查看安装数量、选择原有发布源、HEAD 查询下载大小、确认后下载、字节／文件进度、取消及失败重试。支持无 Content-Length 的不定长下载；未知大小显示不确定进度，不用假定百分比。任务状态可跨页面保留，顶部入口可以返回查看／取消；关闭程序会取消任务并等待暂存清理。下载与图片安装不接触存档或撤销历史；完成后重新进入物品或地图页面即可读取新图片。

图片包先下载到独立临时文件，再解压到临时目录；检查支持的文件名、路径、重复项、长度、PNG 头／尺寸和结尾。支持图片位于单层或多层目录，按原生图片命名扁平化安装；无支持图片的包不会替换旧库。限定下载与展开规模，验证成功后交换目录；取消、网络错误、无效包及最终目录交换失败会保留或恢复旧库并清理暂存文件。安装提交阶段不可中断；备份目录如因系统文件锁无法删除，会保留备份，已完整安装的新库可继续使用。沿用原发布源，未在本次验证中对公网实际下载大型图片包，也不宣称旧图片包覆盖全部新版物品。

编辑页面已改为按需加载。当前构建入口脚本约 68.6 kB，共享 Vue／语言模块约 389.1 kB，地图页约 50.1 kB，原有单包超过 500 kB 的警告消失；这只是构建结果，不代表 Windows 启动耗时已经实测。新增行为仅在 Vue 与工作台桥接中实现，未改动 NHSE.Core 或 NHSE.Injection。

图像安装验证使用本地模拟 HTTP 内容及临时目录，覆盖 HEAD、不定长传输、错误状态、截断、无效 PNG、重复及越界路径、取消清理与目录交换回滚。主画布在三种宽度下验证跨分区、临时手势、原工具保留、取消回退、边界限制与相邻格子定位；带分区坐标的合成地图用于显示核对，真实原生地形图与系统手势保留 Windows 验收项。

## 体验优化：粘贴预览、任务表单与导航分组

地图的“粘贴”按钮与 Ctrl/Cmd+V 先打开只读预览。琥珀色标出实际变化格，包括多格物品的扩展格及被替换物品清理后的旧占地；同时显示计划放置条数、真实变化格数和替换旧物品数。单物品铺满选区沿用完整占地去重规则，多记录保留相对布局和空隙。超出当前分区视图但仍在地图内的变化格单独计数，不会静默裁掉；越界或碰撞显示原有校验错误，并禁用确认。与目标完全相同的粘贴提示无需修改，不创建多余历史。

选择新位置、改变选区、物品图层或重叠保护会重新预览。请求使用短延迟合并和版本号，旧位置的迟到结果不能覆盖新位置，也不能用于确认。网格中 Enter 或“确认粘贴”才提交，Esc 取消并返回网格焦点。预览基于当前已应用数据，不包含属性区未应用的草稿；存在草稿时明确提示粘贴后将重置。预览在独立解码层执行，复用真实粘贴的放置和碰撞规划；仅确认后的原有提交路径写存档，保留一步撤销。房屋和背包的现有直接粘贴行为保持。NHSE.Core 和 NHSE.Injection 未修改。

高级编辑按任务分组：邮箱提供内容、附件、日期与状态、寄件方、收件方和原始参数，全部 30 个字段仍可编辑。正文显示 UTF-16 长度计数及文字预览，附件沿用现有物品目录。寄件方说明玩家／居民／NPC 字段共用存储，避免把并存的字段当作独立身份。日期哨兵、未知状态和数值保持原样，不强制归一化。居民、记忆、物品与房间字段也按内容归组。搜索会自动展开命中组；未命中显示明确空状态。提交和导航校验完整草稿，搜索过滤或折叠的无效字段会自动展开并聚焦，保留完整 64 位整数精度。

## 玩家图鉴、资料补齐与状态修复

物品图鉴和改造款式图鉴放在“玩家进度”内，支持搜索、分页、逐条原始标记编辑。分类批量操作沿用旧 ItemReceivedEditor 的范围：全部物品、家具、昆虫、鱼类、艺术品和海洋生物；包含有效本体款式，并提供仅修改款式模式。家具排除四类生物／艺术品，批量标记排除旧列表中的不可收集物品；全部清除遵循旧界面对物品位及有效款式位的规则，不清除未映射的原始款式位。确认框固定显示实际分类与操作，搜索不会缩小分类批量范围。每批为一次撤销，未改变数值不增加历史。

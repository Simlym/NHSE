第五批 A 验证覆盖列优先坐标索引、新旧地图物品宽度和原点差异、地图外部区域拒绝、建筑填充字节及有符号标记保留、两层物品写入、扩展格定位删除、碰撞与越界原子拒绝、多区域完整字节撤销，以及新版地图的加密重载和哈希。浏览器回归覆盖语言切换保留草稿、导航前应用草稿、物品图层、建筑末位与三种窗口宽度的地图选择。地砖图案使用明确的存储槽位索引，不宣称它与预览图坐标对应。地图图片复用原生 MapRenderer；Windows 实际渲染和高级窗口仍需实机验收。

第五批 B 验证覆盖六类文件（`.nhl`、`.nht`、`.nhb`、`.nha`、`.nhlf`、`.nhmd`）的完整往返、单分区文件的行优先布局、旧 40 栋建筑文件保留末六项、7/9 列物品和活动标记转换、地砖图案空值填充、笔刷边界与随机变体撤销、跨分区占位清理、道路字段隔离及地形外围保护。活动标记按每格一位、行优先索引读写，修复了旧代码长度和坐标宽度错误，以及原地图窗口无法持久保存标记的问题。单分区地形同时修正了原安全边界判断和 14 字节导出步长。

导入前检查文件大小，转换时保留确认；不接受历史错误导出产生的超长文件。批量清理可能移除根格位于相邻分区的物品，以避免遗留扩展格，界面有明确说明。浏览器验证覆盖批量取消、草稿笔刷、图层隔离、文件取消／错误时历史不变和窄屏。文件选择框、PNG 导出及原生地图渲染仍需 Windows 实机验证。

第五批 C 支持陆地／水域与三种拐角预设、拖拽路径插值、指针取消及整笔撤销。拖拽开启后，字段作为笔刷模板，导航不会把模板写入所选格。生成支持当前字段、编号／名称排序配方及 `.nhi` 文件，跳过占用位置并报告实际完成数量；配方排除建造套件，单次最多 10,000 个对象。NHI 记录强制设置为掉落状态，其余参数保留。成功生成或替换后，单格表单恢复为实际存档值，防止导航时把生成模板额外写入所选格。

参数批改提供属性、比较符与按顺序修改规则，只处理所选范围内的根物品；扩展格坐标不直接开放写入。全部变更先在副本上校验并重建占位，碰撞或越界时整批不写入。数值通过十进制文本传递，支持完整 64 位原始值。按当前物品替换／删除比较完整八字节参数。原文本批处理的多指令组、属性引用及随机表达式尚未迁移；仍可进入高级地图窗口使用。

本批验证覆盖 7/9 列地图生成原点、碰撞跳过、边界终止、配方排序和排除规则、NHI 参数保留、64 位字段、规则错误及碰撞原子拒绝、完整字节撤销重做和加密重载。浏览器验证覆盖整笔命令、Esc／指针取消、三种宽度下的路径坐标、文件取消、语言切换保留条件及模板不产生额外单格写入。Windows 的 WebView2 指针事件、原生文件选择及实际地图图片仍需实机验收。

网格交互统一使用单击、拖拽矩形、Ctrl/Cmd 点选增减、Shift 点选扩展、方向键移动与 Shift+方向键扩展。Ctrl/Cmd+A 只选择当前可见网格；Ctrl/Cmd+C/V 使用当前存档内共享的编辑器剪贴板，支持地图物品与房间之间粘贴；地形剪贴板独立。它不读写系统文本剪贴板。输入框内保留原生文本快捷键。Delete／Backspace 清空选区，R 旋转，Esc 取消，工具条提供相同操作和帮助说明。

复制只读取已应用的数据，不修改存档或撤销历史；物品复制按根记录去重并重建完整占位，空白格不清除目标。单记录粘贴按实际占位填充选区，多记录保留相对布局。整次粘贴、旋转或删除均为一个撤销步骤，碰撞和越界整批拒绝；明确关闭防重叠时，会完整移除被替换物品的占位。指针取消恢复原选区，视图载入期间的复制／粘贴按顺序处理，离开页面后不保留排队动作。房间表单重新进入时会读取实际记录，防止缓存页面误把已有物品当作空格。

本批模型验证覆盖只读复制、完整原始参数、跨地图图层与房间粘贴、相对布局及空白间隙保留、按占位填充、扩展格去重、完整字节撤销、边界／类型／碰撞拒绝、重叠替换及加密重载。浏览器验证覆盖框选、Ctrl/Cmd/Shift 组合、快捷键与文本输入隔离、视图延迟后的粘贴、跨页剪贴板、房间缓存、全选清空的一次命令和窄屏坐标。图库列表仍使用原有单选交互；Windows WebView2 实机快捷键与系统输入法仍需验收。

背包、仓库与回收箱已接入统一网格交互和存档内物品剪贴板，可与地图、房间交换物品。选区按实际显示列数建立，适配窄屏换行；搜索、分页、玩家或容器切换时重置选区，只全选当前可见且已解锁的格子。筛选后的视觉坐标映射回真实存档槽位；背包物品每件只占一个槽位，保留完整八字节参数。单条剪贴板填充选区，多条按相对布局粘贴，空白来源不清空目标。锁定格、无效坐标或越界整批拒绝，粘贴、删除与旋转各为一次撤销。模型验证覆盖锁定格原子拒绝、筛选映射、跨容器与地图／房间粘贴、完整字节撤销重做及加密重载；浏览器验证覆盖宽窄屏框选、多选、快捷键、文本输入隔离与锁定格全选排除。
